C. AKTIVITAS 1: EKSPERIMEN 10 + 20

let a = "10";
let b = "20";
console.log(a + b);

Output Program: 1020

Penyebab: Karakter + pada nilai bertipe String berfungsi sebagai operator penggabungan string (concatenation), bukan penjumlahan matematika.

Apakah a dan b bertipe Number? Tidak, keduanya bertipe String karena diapit oleh tanda petik ganda (" ").

D. AKTIVITAS 2: MENEMUKAN TIPE DATA

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama string string Data Teks / Karakter
umur number number Data Angka / Numerik

Temuan (Perbedaan String vs Number): String digunakan untuk merepresentasikan teks/karakter yang diapit tanda petik dan jika digabung menggunakan + akan menempel. Number digunakan untuk representasi nilai numerik yang dapat dioperasikan dengan kalkulasi matematika.

G. TANTANGAN: PROGRAM HITUNG NILAI

let tugas = Number(prompt("Masukkan nilai tugas: "));
let uts = Number(prompt("Masukkan nilai UTS: "));
let uas = Number(prompt("Masukkan nilai UAS: "));
let rataRata = (tugas + uts + uas) / 3;
console.log("Rata-rata = " + rataRata);

Algoritma Program:

  1. Mengambil input nilai tugas, UTS, dan UAS dalam bentuk string.
  2. Mengeksekusi konversi tipe data dari String menjadi Number menggunakan fungsi Number().
  3. Menghitung hasil rerata menggunakan rumus (tugas + uts + uas) / 3.
  4. Menampilkan nilai rata-rata hasil kalkulasi ke konsol/layar.

H. THINK PAIR SHARE

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Fungsi prompt() secara *default* selalu mengembalikan nilai bertipe String. Jika tidak dikonversi ke Number, pengoperasian simbol + akan menggabungkan teks, bukan menjumlahkannya.
Apa perbedaan "10" dengan 10? "10" adalah String (teks berisi karakter angka 1 dan 0), sedangkan 10 adalah Number (nilai numerik asli yang bisa dihitung).
Apa yang terjadi jika lupa Number()? Hasil operasi matematika dasar seperti penjumlahan akan menghasilkan teks gabungan yang salah (contoh: "10" + "20" = "1020").
